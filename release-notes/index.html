Installer integrity

The installer is not currently signed with a commercial code-signing certificate. Windows SmartScreen may therefore show an “unrecognised app” warning. Verify the downloaded file before running it:

FilenameBenchReport-Pro-0.4.0-Setup.exe
Size99,677,579 bytes (95.1 MB)
SHA-256BF47ADFB5369149F72965E9CB2424CE20888D733F7261D4CE0CEB6640FE179C7

In PowerShell, run:

Get-FileHash .\BenchReport-Pro-0.4.0-Setup.exe -Algorithm SHA256

Only continue if the returned hash exactly matches the published value above.

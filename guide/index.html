User guide

From Touchstone files to an acceptance report.

BenchReport compares one-port and two-port S-parameter measurements entirely in your browser. Nothing is uploaded.

Try the complete workflow

Three synthetic filter measurements are included.

Open BenchReport

1. Load measurements

Drop one or more .s1p or .s2p files into the measurement area. Use the checkbox to hide a trace, the colour control to distinguish units, and the reference selector to emphasise a golden measurement.

2. Build acceptance rules

Each rule selects an S-parameter, frequency band, comparison direction, and dB threshold. “At least” is useful for passband S21 requirements; “at most” is useful for return loss and stopband requirements.

3. Review statistics

BenchReport identifies extrema and their frequencies. For the displayed trace it also estimates the 3 dB bandwidth, centre frequency, and S21 peak insertion loss.

4. Save templates and projects with Pro

BenchReport Pro templates store reusable rule sets on the computer. A .brp project stores measurements, rules, display settings, report fields, and an optional logo in one portable JSON document.

5. Export a report

Add DUT, engineer and notes in Free, or add full project metadata and company branding in Pro. Select Export / print report, then choose “Save as PDF” in the print dialog.

Engineering review remains required.

BenchReport is analysis and documentation software, not a calibrated instrument. Verify results against the source measurement and your approved process.
